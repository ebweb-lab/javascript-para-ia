# JavaScript para IA

Curso práctico de inteligencia artificial con JavaScript puro: sin librerías, construyendo cada pieza desde cero y viéndola funcionar en el navegador.

## Lecciones

| # | Lección | Qué construyes |
|---|---------|----------------|
| 1 | [Una neurona desde cero: un perceptrón en JS puro](leccion-01-perceptron/) | Una neurona artificial que aprende en vivo a separar dos grupos de puntos en un `<canvas>`. |
| 2 | [Varias neuronas en capas: una red que aprende XOR](leccion-02-red-multicapa/) | Una red de dos capas entrenada con retropropagación que separa XOR, un círculo y una espiral. |

## Cómo usar el repositorio

1. Descarga el repositorio (botón **Code → Download ZIP**) o clónalo:

   ```bash
   git clone https://github.com/ebweb-lab/javascript-para-ia.git
   ```

2. Entra en la carpeta de la lección y abre `index.html` con doble clic. No hace falta instalar nada.
3. Sigue el `README.md` de cada lección: explica la teoría, el código línea por línea y trae ejercicios para practicar.

## Requisitos

- JavaScript básico: variables, funciones, clases, arreglos y bucles.
- Un navegador moderno (Chrome, Edge o Firefox).
- Node.js es opcional: solo para algunas pruebas rápidas en la terminal.
