Una neurona desde cero

Construimos un perceptrón en JavaScript puro —sin librerías— y lo vemos aprender a separar dos grupos de puntos en un canvas.

1. La idea

Una neurona artificial es una función muy simple: recibe números, los multiplica por unos pesos, suma un sesgo y decide +1 o -1.

z = w₁·x + w₂·y + b   →   salida = z ≥ 0 ? +1 : −1

Con dos entradas (x, y), la ecuación w₁·x + w₂·y + b = 0 es una recta. Todo lo que queda a un lado es clase A; al otro, clase B. Aprender = mover esa recta hasta que separe bien los puntos.

2. Cómo aprende

La regla del perceptrón (Rosenblatt, 1958) es casi de sentido común. Por cada ejemplo:

  1. Predice.
  2. Calcula error = objetivo − predicción (vale −2, 0 o 2).
  3. Si falló, empuja cada peso: w += tasa · error · entrada, y el sesgo: b += tasa · error.

Una pasada completa por todos los datos se llama época. Si los datos se pueden separar con una recta, está demostrado que el perceptrón termina encontrándola.

3. El código

Todo el "cerebro" cabe en una clase (perceptron.js):

class Perceptron {
  constructor(numEntradas, tasaAprendizaje = 0.1) {
    this.pesos = Array.from({ length: numEntradas }, () => Math.random() * 2 - 1);
    this.sesgo = Math.random() * 2 - 1;
    this.tasa = tasaAprendizaje;
  }

  sumaPonderada(entradas) {
    let z = this.sesgo;
    for (let i = 0; i < this.pesos.length; i++) z += this.pesos[i] * entradas[i];
    return z;
  }

  activacion(z) { return z >= 0 ? 1 : -1; }

  predecir(entradas) { return this.activacion(this.sumaPonderada(entradas)); }

  entrenar(entradas, objetivo) {
    const error = objetivo - this.predecir(entradas);
    if (error !== 0) {
      for (let i = 0; i < this.pesos.length; i++) {
        this.pesos[i] += this.tasa * error * entradas[i];
      }
      this.sesgo += this.tasa * error;
    }
    return error;
  }
}

Uso mínimo:

const n = new Perceptron(2);
n.entrenar([0.5, 0.8], 1);    // "este punto es clase A"
n.entrenar([0.3, -0.6], -1);  // "este es clase B"
n.predecir([0.4, 0.9]);       // → 1 o -1

5. Qué observar

  • Pulsa Un paso varias veces: la recta solo se mueve cuando el punto resaltado está mal clasificado.
  • La recta aprendida casi nunca coincide exactamente con la secreta. Basta con que separe los datos que ha visto. Esa diferencia es la semilla del concepto de generalización.
  • Sube la tasa a 1: converge, pero a saltos. Bájala a 0.001: suave pero lento.

6. Ejercicios

  1. Rompe la neurona. Pulsa Vaciar y dibuja un grupo A en el centro rodeado de puntos B. Entrena. ¿Por qué nunca converge? (Pista: busca "problema XOR" y "separabilidad lineal".)
  2. Sin sesgo. En perceptron.js comenta la línea que actualiza this.sesgo y fíjalo a 0. ¿Qué restricción aparece en la recta?
  3. Otra activación. Crea un método sigmoide(z) que devuelva 1 / (1 + Math.exp(-z)) y muestra en consola la "confianza" de cada predicción.
  4. Tres entradas. Instancia new Perceptron(3) y entrénalo para la puerta lógica AND con entradas [a, b, 1]. Luego prueba OR. Luego XOR.
  5. Mide. Cuenta cuántas épocas tarda en converger con 20, 80 y 300 puntos. Haz una tabla.
